# Research → Brief

Ask a research question. An agent plans web searches, reads pages, and
writes a **cited brief** — with the whole trace visible and guardrails
enforced (step cap, read-only tools, cancel anytime).

Portfolio project #3 of 3 (see `SPEC.md`). #1 (`meeting-to-actions`)
shows structured extraction, #2 (`docs-to-answers`) shows retrieval;
this one shows the **agent loop**.
